# 百度文心图片生成技能

基于百度飞桨 AI Studio 星河社区的 ERNIE-Image-Turbo 模型，实现文字生成图片。

## 工作流程

### 第一步：推荐风格

生成图片前，**必须先**根据用户的描述，推荐 3-5 个合适的风格供用户选择。使用 `AskUserQuestion` 工具展示风格选项。

风格列表（从中选择最匹配的推荐给用户）：

| 风格 | 英文标识 | 适合场景 | 默认引导强度 |
|------|---------|---------|------------|
| 写实摄影 | realistic photography | 人物肖像、风景、食物、产品照 | 1.0 |
| 水彩插画 | watercolor illustration | 童话绘本、清新文艺、植物花卉 | 1.2 |
| 油画风格 | oil painting | 古典人像、静物、艺术创作 | 1.5 |
| 二次元动漫 | anime | 角色设计、动漫头像、日系风格 | 1.8 |
| 赛博朋克 | cyberpunk | 科幻场景、未来城市、霓虹灯光 | 2.0 |
| 中国风水墨 | chinese ink painting | 山水、花鸟、传统意境 | 1.5 |
| 像素风 | pixel art | 游戏素材、复古风格、8-bit | 2.5 |
| 扁平插画 | flat illustration | UI设计、图标、简约海报 | 1.5 |
| 3D渲染 | 3D render | 产品展示、立体场景、材质表现 | 2.0 |
| 吉卜力风格 | ghibli style | 温暖治愈、自然风景、宫崎骏风 | 2.0 |
| 蒸汽朋克 | steampunk | 机械装置、维多利亚时代、齿轮 | 2.0 |
| 极简主义 | minimalist | 简洁构图、留白、现代设计 | 1.5 |
| PPT商务风 | ppt business style | 方案演示、商务汇报、架构图 | 1.2 |
| 可爱卡通风 | cute cartoon style | 表情包、儿童插画、Q版角色 | 1.8 |
| 国潮风 | chinese trendy style | 国风设计、文创产品、品牌海报 | 1.8 |
| 科技蓝调风 | tech blue style | 技术方案、AI概念图、数据可视化 | 1.5 |
| 温暖治愈风 | warm cozy style | 生活场景、情感插画、家居设计 | 1.2 |

**新增风格说明**：
- PPT商务风：简洁专业，适合技术方案、架构图、演示文档配图
- 可爱卡通风：圆润线条，明亮色彩，Q版造型，适合表情包和儿童内容
- 国潮风：融合传统中国元素与现代设计，适合文创和品牌宣传
- 科技蓝调风：蓝紫渐变，科技感线条，适合AI和技术主题
- 温暖治愈风：暖色调，柔和光影，适合生活场景和情感表达

推荐风格时，将风格关键词追加到用户 prompt 末尾，帮助模型更好地理解意图。

### 第二步：确认色系

在用户选择风格后，**必须**询问用户色系偏好，推荐 3-4 个合适的色系选项。使用 `AskUserQuestion` 工具展示色系选项。

色系推荐列表：

| 色系 | 英文标识 | 适合场景 |
|------|---------|---------|
| 蓝灰科技系 | blue gray tech | 技术方案、架构图、AI主题、商务PPT |
| 马卡龙清新系 | macaron pastel | 可爱风格、儿童插画、文创设计 |
| 国潮红金系 | chinese red gold | 国潮风、传统主题、节庆海报 |
| 黑白极简系 | black white minimal | 极简主义、产品展示、现代设计 |
| 暖橙治愈系 | warm orange cozy | 生活场景、情感插画、家居设计 |
| 森林自然系 | forest nature green | 风景、环保主题、自然产品 |
| 赛博霓虹系 | cyber neon purple | 科幻、未来城市、电竞主题 |

将选中的色系关键词融入 prompt，如 `blue gray color palette`。

### 第三步：确认尺寸

根据图片用途，推荐合适的尺寸：

| 尺寸 | 比例 | 适合场景 |
|------|------|---------|
| 1024x1024 | 1:1 | 通用方图、头像 |
| 1376x768 | 16:9 | 横版海报、文章封面、PPT配图 |
| 1264x848 | 3:2 | 摄影风格横图 |
| 1200x896 | 4:3 | 传统横屏 |
| 896x1200 | 3:4 | 传统竖屏、海报 |
| 848x1264 | 2:3 | 摄影风格竖图 |
| 768x1376 | 9:16 | 手机壁纸、短视频封面 |

如果用户未指定尺寸，根据场景智能推荐（人像/海报选竖版，风景/封面选横版，PPT配图选16:9，不确定用 1024x1024）。也可以用 `AskUserQuestion` 和风格、色系一起询问。

### 第四步：选择引导强度

根据用户选择的风格，使用上表中的**默认引导强度**（guidance_scale）。引导强度控制模型遵循 prompt 的程度：
- 较低值（1.0-1.5）：更自由、更自然，适合摄影、写实风格
- 中等值（1.5-2.0）：平衡创意与遵循度，适合大多数插画风格
- 较高值（2.0-3.0）：更严格遵循 prompt，适合特定风格如像素风、赛博朋克

如果用户有特殊要求，可以在 1.0-3.0 范围内调整。

### 第五步：生成图片

调用 `scripts/generate.py` 脚本生成图片：

```bash
python scripts/generate.py \
  --prompt "用户描述, 风格关键词, 色系关键词, 质量修饰词" \
  --size "1024x1024" \
  --n 1 \
  --guidance 1.5 \
  --output "output.png"
```

**脚本位置**：`scripts/generate.py`（相对于技能目录）

**关键参数**：
- `--prompt`：图片描述（必须将风格关键词、色系关键词融入）
- `--size`：图片尺寸，默认 1024x1024
- `--n`：生成数量，1-4，默认 1
- `--guidance`：引导强度，根据风格选择默认值，范围 1.0-3.0
- `--output`：输出文件路径，默认 output.png
- `--seed`：随机种子，不指定则随机
- `--format`：返回格式，b64_json 或 url，默认 b64_json

### 第六步：展示结果

生成完成后，告知用户图片保存路径。如果生成了多张图片，列出所有文件路径。

## Prompt 优化技巧

将用户描述与风格关键词组合时，遵循以下模式：

```
[用户描述], [风格关键词], [质量修饰词]
```

质量修饰词示例：`masterpiece, best quality, highly detailed, 8k`

例如用户说"画一只猫"：
- 写实摄影：`一只可爱的猫咪坐在窗台上, realistic photography, highly detailed, 8k`
- 水彩插画：`一只可爱的猫咪坐在窗台上, watercolor illustration, soft colors, artistic`
- 二次元动漫：`一只可爱的猫咪坐在窗台上, anime style, vibrant colors, kawaii`

## API 配置

API Key 配置在技能目录的 `.env` 文件中：
```
AISTUDIO_API_KEY=your_api_key_here
```

首次使用时，如果 `.env` 文件不存在或 API Key 为空，提示用户前往 https://aistudio.baidu.com/account/accessToken 获取 Access Token，并写入 `.env` 文件。

## 错误处理

- API Key 无效：提示用户检查 `.env` 中的 `AISTUDIO_API_KEY`
- 网络错误：提示用户检查网络连接
- 生成失败：建议用户简化 prompt 或更换风格重试
